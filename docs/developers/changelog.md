# Developer changelog

## 20 November 2026

- The API, keys and webhooks move to Trizlink's new open platform. The address stays `https://api.trizlink.com/v1`.
- New: the MCP connection for AI assistants, calendar feeds and two-step sign-in.
- The API is now on every plan, Free included. Owners and admins may give change and delete; members give read only.
- Keys made before today were already revoked. Webhook addresses moved over with a new secret and arrive paused.
