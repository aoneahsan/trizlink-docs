# Two-step sign-in

**A six-digit code from your phone after you sign in.** Turn it on under **Settings → Security**: scan the code
with an authenticator app, type the six digits, save the ten recovery codes.

- **Recovery codes** each sign you in once without your phone. Using one emails you.
- **Remember this browser for 7 days** is off unless you tick it on the code screen. It never counts for showing a
  key again or for admin pages.
- **Trizlink staff** need a code in the same sign-in before any admin page.
- **Lost your phone and your codes?** Write to us. After two independent checks support turns two-step off, quotes a
  reference, and Trizlink emails you.
