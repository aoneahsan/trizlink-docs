## About TrizLink

TrizLink is a web and mobile link-management platform: branded short links, link-in-bio pages, QR codes, click analytics, workspaces and teams, custom domains, an API, a browser extension, and a set of free client-side utility tools. It is built with React and TypeScript on the web, Capacitor for the mobile app, and Firebase/Firestore on the backend. Sign-in is Google-only.

If you want to understand the product, start with the [Introduction](/intro), then the [Quick Start](/getting-started/quick-start).
