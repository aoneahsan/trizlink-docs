A white-label licence is Trizlink, run by the Trizlink team under another company's name. We host it, deploy it on
a domain the buyer owns, and replace Trizlink's name, logo and colours with theirs. The buyer offers it to their
own customers. The source code stays with us.

The other path is the **source buyout**: the buyer receives the code of every repository that builds the web app
and the Android app, and Trizlink comes off sale for everyone else. The buyer also pays a royalty of 7% of the gross
revenue Trizlink earns, every quarter, for as long as it earns; the
[licence terms](https://trizlink.com/white-label/license-terms#buyout) set out how it works.

Prices are not repeated here. The [pricing page](https://trizlink.com/white-label/pricing) asks the licensing
service for every number it shows, and that number is the one the payment page asks for.

## What a licence is not

A licence is not ownership. It carries no source code, it is not exclusive until somebody buys the product
outright, and changes made only for one buyer are [custom work](https://trizlink.com/white-label/custom-work),
quoted and paid separately. The full wording is on the
[licence terms](https://trizlink.com/white-label/license-terms) page and in the
[Terms of Service](https://trizlink.com/terms#white-label).

A deployment inherits Trizlink's limits along with its features. Social publishing is built and switched off,
sign-in is Google only, and serving short links from a workspace's own domain is not switched on. Each changes in
a white-label deployment when it changes in Trizlink.
