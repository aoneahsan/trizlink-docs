The Trizlink API is now part of the **[Developers section](/developers)**: the same address
(`https://api.trizlink.com/v1`), now on every plan, Free included, with an MCP connection for AI assistants,
signed webhooks, calendar feeds and two-step sign-in beside it.

- [Access keys, scopes and limits](/developers/access-keys)
- [The API and its OpenAPI file](/developers/api-reference)
- [Connect Claude, ChatGPT, Claude Code or Cursor](/developers/assistants)
- [Webhooks](/developers/webhooks)

Keys made before 20 November 2026 were already revoked. Webhook addresses moved over with a new signing secret and
arrive paused; read the new secret under **Settings → Other apps** and resume them.
